CMAKE_BUILD_TYPE
----------------

Specifies the available build type on single-configuration generators.

This statically specifies the build type (configuration) used for the build
tree. Default names are empty, ``Debug``, ``Release``, ``RelWithDebInfo``
and ``MinSizeRel``. Custom types can be defined as well.

See :manual:`cmake-buildsystem(7)` for more details on build configurations.
