CMP0211
-------

.. versionadded:: 4.4

A file may belong to at most one :ref:`file set <file sets>` in a target.

In CMake 4.3 and below, it is possible to specify the same file in different
file sets of a target.

In CMake 4.4 and above, a file, per target, can belongs only to one file set or
outside of any file set.

The ``OLD`` behavior for this policy is to accept the same file in different
file sets of atarget. The ``NEW`` behavior enforce the unicity of files for all
the file sets of a target.
