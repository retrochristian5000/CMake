cuda-check-support
------------------

* The :module:`CheckCUDASourceCompiles` module was added to
  provide a ``CHECK_CUDA_SOURCE_COMPILES`` macro.

* The :module:`CheckCUDASourceRuns` module was added to
  provide a ``CHECK_CUDA_SOURCE_RUNS`` macro.

* The :module:`CheckCUDACompilerFlag` module was added to
  provide a ``CHECK_CUDA_COMPILER_FLAG`` macro.
