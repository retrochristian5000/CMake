filter-debug-find
-----------------

* The :manual:`cmake(1)` command line tool's gained a
  ``--debug-find-pkg`` option to enable debug messages for
  :command:`find_package` calls scoped to calls involving given packages.

* The :manual:`cmake(1)` command line tool gained a ``--debug-find-var``
  option to enable debug messages for specific find_* calls
  that use given var result variable.
