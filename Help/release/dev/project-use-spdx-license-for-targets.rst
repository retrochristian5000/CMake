project-use-spdx-license-for-targets
------------------------------------

* The :command:`project` command gained a ``USE_SPDX_LICENSE_FOR_TARGETS``
  option that initializes the :prop_tgt:`SPDX_LICENSE` property of targets
  from the project's ``SPDX_LICENSE``.  See also the
  :variable:`PROJECT_USE_SPDX_LICENSE_FOR_TARGETS` and
  :variable:`<PROJECT-NAME>_USE_SPDX_LICENSE_FOR_TARGETS` variables.
