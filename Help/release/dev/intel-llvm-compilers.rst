intel-llvm-compilers
--------------------

* The Intel oneAPI NextGen LLVM compilers are now supported with
  compiler id ``IntelLLVM``:

  * On Linux, support is available for ``icx`` (C), ``icpx`` (C++),
    and ``ifx`` (Fortran).

  * On Windows, support is available for ``icx`` (C and C++).

  The Intel oneAPI Classic compilers (``icc``/``icpc``, ``icl``, ``ifort``)
  remain supported with compiler id ``Intel``.
